# Costs

This laboratory is **not free**. EC2, application load balancing, public IPv4, EBS, CloudWatch, data transfer and S3 may all incur charges. AWS price and Free Tier eligibility vary. Check the AWS Pricing Calculator for `eu-west-2` before deployment. Do not leave the lab running between sessions.

Cleanup requires deleting CloudFormation stacks, removing injected faults, destroying Terraform resources and explicitly dealing with S3 version history. Inspect all plans and resource lists before deletion.
